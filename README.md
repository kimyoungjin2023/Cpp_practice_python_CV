## 🧠 프로그램 메모리 구조 개요

> **Stack과 Heap은 Flash(SSD)가 아니라 RAM 안의 영역입니다**

```
┌────────────────────────┐
│   Code (실행 코드)     │
├────────────────────────┤
│   Global / Static      │
├────────────────────────┤
│        Heap            │  ← 동적 메모리
│                        │
├────────────────────────┤
│        Stack           │  ← 함수 / 지역 변수
└────────────────────────┘
```

---

## 1️⃣ Stack (스택)

* 함수 호출 시 자동 생성
* 함수 종료 시 자동 해제
* 매우 빠르지만 크기가 작음

```cpp
void func() {
    int x = 10; // stack
}
```

⚠️ 함수가 끝나면 **스택 메모리는 즉시 소멸**됩니다.

---

## 2️⃣ Heap (힙)

* 실행 중 동적 할당
* 크기가 큼
* C++에서는 해제 책임이 개발자에게 있음

```cpp
int* p = new int(10); // heap
delete p;             // 반드시 해제
```

---

## 3️⃣ Stack vs Heap 비교

| 구분   | Stack | Heap      |
| ---- | ----- | --------- |
| 위치   | RAM   | RAM       |
| 관리   | 자동    | 수동 / 반자동  |
| 속도   | 매우 빠름 | 상대적으로 느림  |
| 크기   | 작음    | 큼         |
| 주 용도 | 지역 변수 | 이미지, 컨테이너 |

## 📦 vector 개념 (C++)

> **vector는 포인터가 아니라, 내부에 포인터를 가진 컨테이너 객체입니다**

```cpp
vector<int> v;
v.push_back(1);
v.push_back(2);
```

### 내부 구조 (개념)

```
stack                heap
┌──────────┐          ┌──────────────┐
│ vector   │ ───────▶ │ data array   │
└──────────┘          └──────────────┘
```

---

## 🖼️ OpenCV Mat 메모리 구조

```cpp
cv::Mat frame;
```

```
stack                heap
┌──────────┐          ┌──────────────┐
│ Mat      │ ───────▶ │ image pixels │
└──────────┘          └──────────────┘
```

* 객체는 stack
* 이미지 데이터는 heap
* 얕은 복사 구조 → **실시간 처리에 매우 유리**

## ✅ 정리

* Stack / Heap은 **RAM 내부 구조**
* vector / Mat은 **객체는 stack, 데이터는 heap**

* C++은 구조를 이해해야 성능과 안정성을 얻을 수 있음
